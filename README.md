# Finn 个人数字岛屿网站源码 (艺术润色版)

> **“让想法被理解，也被实现。保持真实，让热爱有回响。”**

这是全面润色与打磨升级后的 Finn（孟乐 / 骁清）个人官方数字岛屿网站源码。  
遵循国际先锋设计水准（Awwwards / Godly 风格），在保留**纯原生 0 构建依赖、开箱即用**特性的同时，实现了顶级的视觉质感与微交互体验。

---

## 核心升级亮点

1. **双主题美学 (Dual Aesthetic Modes)**：
   - **日出白纸 (Paper & Ink)**：高质感自然纸张底色（`#F8F6F1`）、墨色文字与标志性赭红点缀（`#D9532F`），具备极具呼吸感的杂志画册排版。
   - **深夜星屿 (Midnight Nebula)**：专为夜间与创作者设计的暗黑沉浸模式（`#0D0F13`），搭配柔和星尘微光与发光毛玻璃卡片，支持本地记忆一键切换。
2. **动态潮汐星轨背景 (Ambient Canvas)**：
   - 原生 HTML5 Canvas 实时渲染柔和流淌的潮汐海岸波纹与漂移星尘粒子，支持鼠标微斥力互动，页面后台时自动降低帧率节能。
3. **3D 视差透视名片 (3D Identity Parallax)**：
   - Hero 核心立体名片支持真实 3D 鼠标跟随倾斜与流光掠影；
   - 包含可点击盖印下压的“KEEP real.”实体印章动效；
   - 内置 UTC+8 青岛实时时钟挂件。
4. **Web Audio 触觉微音效 (Tactile Sound)**：
   - 基于浏览器 Web Audio API 动态合成轻微按键音、实体盖印重低音与提示音，零外部音频文件加载，支持一键随时静音。
5. **工作流与实践升维 (Interactive Portfolio)**：
   - **AI-Koubo Studio**：交互式 4 步创作流水线（想法 ➔ 脚本 ➔ 口播 ➔ 分发），点击不同环节动态呼应创作手记与思考；
   - **知识星港 / 冰藏知识库**：太空轨道与空间概念视觉展卡；
   - **安心答**：社会价值与科技向善问题卡片；
   - **次级项目手风琴**：全平滑过渡展开折叠与分类标签筛选（全部 / AI 工作流 / 空间交互 / 独立开发）。
6. **双层压缩哲学模型与杂志随笔 (Notes on Expression)**：
   - 视觉图解：“语言是全损压缩，意图是行动解压”（人际共情模型 vs AI 协作模型）；
   - 4 篇深度精选随笔，采用现代杂志专栏版式与 Pull-quote 金句。
7. **生活手感 Bento 展台 (Life & Person)**：
   - 现代便当格（Bento Grid）生动展示辩论阅读、金巴黎调酒师认证、咖啡拉花、街头长板与多行业真实历练。
8. **合作意向快速拼装器 (Collab Kickstart)**：
   - 访客选择想要探索的方向并填入称呼/主题，自动实时组装得体专业的打招呼初稿，支持一键复制。
9. **微信二维码卡片与大图灯箱 (Lightbox)**：
   - 微信卡片支持一键复制微信号 `18300425760`；
   - 点击二维码可弹出毛玻璃全屏大图预览灯箱。
10. **全平台自适应适配 (Responsive Design)**：
    - 针对桌面宽屏、笔记本、平板以及手机端（iPhone / Android）全断点精调，无文字溢出或挤压折行。

## 本地预览方法

无需安装任何 `npm` 或前端打包工具，直接在项目目录下运行 Python 简易服务即可：

```bash
# 启动本地服务
python3 -m http.server 8000 --directory dist
```

然后在浏览器打开：[http://localhost:8000](http://localhost:8000)。

---

## 线上部署

将 `dist/` 目录下的所有文件上传至任何支持静态托管的服务商（如 GitHub Pages、Cloudflare Pages、Vercel、Netlify 或各类独立服务器），即可直接获得全球疾速访问。
